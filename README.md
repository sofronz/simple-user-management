# Simple User Management

This is a simple user management project that demonstrates fetching and displaying user data from an external API, as well as implementing a search feature and user detail pages.

## Features
- Display a list of users fetched from a public API
- Search users by name or email
- View detailed information for each user

## Live Demo
You can access the project here: [Simple User Management](https://sofronz.github.io/simple-user-management/index.html)

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap (for styling)
- Fetch API (for data retrieval)

## Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/sofronz/simple-user-management.git
   ```
2. Open `index.html` in your browser to view the application locally.
